## 1. Flip off the mocks

Set `USE_MOCK=0`. Walk every endpoint the frontend calls and diff the real response against
the fixture. Where they differ, **fix the backend to match `docs/CONTRACT.md`** — the
contract wins, not whichever side is more convenient. If the contract itself is wrong,
change the contract first, then both sides.

Common breakages to check deliberately: `null` where the fixture had `[]`, Neo4j integer
objects leaking as `{low, high}` instead of numbers, date objects instead of ISO strings,
`user_id` vs `userId` casing.

## 2. Make it impossible to show a blank screen

Three fallback layers, in order:

1. **Graph down** → serve profiles from `data/profiles/*.json` on disk. Log it, set the
   rail indicator to `OFFLINE`, keep serving.
2. **LLM down or timed out** → return the stored narrative and the deterministic rationale.
   The app degrades to fast-and-factual, which is still a good demo.
3. **Everything down** → `USE_MOCK=1`.

Every fetch in the frontend needs a real error state naming what failed. A white screen in
front of a judge is the worst outcome available; a small clay banner saying "graph
unreachable — serving cached profiles" is genuinely fine and even reads as engineering
maturity.
